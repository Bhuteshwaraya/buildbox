FIRST TIME HERE?

One setup.
Your own simulator.

The website is your download and update home. BuildBox itself opens as a local app and does the simulation work on your computer.

No account or developer tools required. No cloud simulation bill.

  1. 1 Download the preview

    Use the button above. You’ll get the Windows installer from the official BuildBox GitHub release. Google Chrome must already be installed.

  2. 2 Review and install

    Close BuildBox if it’s running. Read the setup agreement, then install for your Windows account. The local simulation engine and its runtimes are included: about 159 MB of program files, plus space for saved work and update backups.

    Setup shows progress and offers an optional desktop shortcut. It does not install a background service or change your drivers.

  3. 3 Open BuildBox

    Find BuildBox in the Start menu. Help explains the include and lock controls. Choose your setup, review the run settings, then start when you’re ready. Computer usage controls let you leave room for other work.

KEEP IT CURRENT

Updates, without losing your work.

For this preview, updates are manual. Return here, read the patch notes and download the next installer. Close BuildBox before running setup. Saved work is kept separately and backed up by the update process.

Automatic update installation is not enabled. Uninstall keeps your saved work and backups. Keep your own copy of anything important, too.

YOUR COMPUTER, YOUR WORK

Small footprint. Clear choices.

Builds and results stay local. This preview adds no installation tracking or analytics. Optional private problem reports are off until you choose to send them; use Help to review the details.

Reports exclude builds, saves, account details and local file paths. GitHub hosts this page and downloads; Ko-fi handles optional donations under their own privacy policies.

KNOW THE BOUNDARIES

A preview, with honest limits.

This release targets Windows 11 on Intel/AMD 64-bit PCs with Chrome. Other systems and ARM devices are not qualified. The latest installer and shutdown changes have isolated checks; the full public download-to-install journey still needs its first live acceptance test.

GPU assistance is optional and applies only to supported work. Results depend on the current model and its assumptions. A winning tested build is not proof of the best possible build in the game.
