# BuildBox

Gear. Talents. Rotation. Optimized together.

Build and rotation simulator for Ardeos in FELLOWSHIP.

[Download](https://bhuteshwaraya.github.io/buildbox/) · [Patch notes](https://bhuteshwaraya.github.io/buildbox/patch-notes.html) · [Discord](https://discord.gg/bJ2hwedf4w)

Free Windows 11 x64 preview. Chrome required. See the download page for setup, updates and limits.

Builds and results stay local. Error reports are optional and off by default. No installation analytics.
